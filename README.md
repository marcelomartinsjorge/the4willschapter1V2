# As Quatro Vontades · Capítulo I · livro interativo

- `index.html` · o livro
- `capitulo1.js` · o roteiro em português: páginas, escolhas, textos (os novos marcados com // NOVO)
- `capitulo1.en.js` · a tradução inglesa (o livro abre em inglês)
- `livro.js` · o motor (páginas, Luz, escolhas, minijogos, som, resumo)
- `livro.css` · o visual
- `content/cap01/chapter-config.js` · codex e ambientes sonoros (o mesmo do capítulo antigo)
- `jogo/` · o jogo "O gelo obedece", aberto dentro do livro
- `REVISAO_CAPITULO1.md` · textos novos para revisar e lista do que falta enviar

Para testar no PC: `jogar.bat` (precisa do Node instalado).
